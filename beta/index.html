① 装 App（四个内置组合，选一个）

四个包是同一个 App（同包名、同签名）：区别只在内嵌了什么。换组合 = 覆盖安装另一个 APK，数据不丢。

APK 放在 GitHub Releases（内嵌环境后单文件可到 114 MB，超过 Pages 的 100 MB 上限）；模块 zip 与 index.json 仍在站内。

③ 起环境

  1. 内嵌了 Ubuntu 的包：装完 App 里点「启动环境」即可（完全离线）。
  2. 最小版（只带 proot）：去 App「更新」页从官方频道装三层（约 96 MB，几分钟）；或下载上面卡片里的离线包 .bin，在 App 里导入。
  3. 终端自检：linuxctl doctor。
