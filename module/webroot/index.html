频道最新—
模块的更新走频道清单里的 module 段，与层更新同一套安全模型： 清单必须通过 Ed25519 验签，验签失败一律拒绝。
下载的 zip 不会自动安装：模块文件在 /data/adb/modules/ 下， 热替换有风险且管理器不认；本页只把它落到 Download/， 再由你在 KernelSU / Magisk 管理器里「从本地安装」。

「下载并暂存脚本包」是另一条路：只更新 bin/ 里的运行时脚本， 解到 cache/updates/bin-packages/<版本>/ 并写 etc/bin-pending， 下次开机由 post-fs-data 同步到 $LINUX_HOME/bin （不热替换正在跑的脚本，所以安全）。撤销： rm -rf cache/updates/bin-packages/<版本> etc/bin-pending， 下次开机自动回落到模块目录里的版本。 
（点「检查模块更新」开始）
