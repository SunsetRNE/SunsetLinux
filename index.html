SunsetLinux

Android 上的原生 DSH 运行环境

正式版（stable）App 0.3.14 · 模块 1.0.37 · 当前推荐 预发布版（beta）下一版候选，可能不稳定

这是什么

  1. Android 上的真 chroot + overlayfs Ubuntu 24.04 环境，跑原生 DSH。
  2. 装 App + KernelSU 模块，即可在手机上得到完整的 DSH 运行环境。
  3. App 有四个包（Root 最小版、Root Ubuntu 版、Root 完整离线版、免 root 最小版、免 root Ubuntu 版、免 root 完整离线版）：内嵌得越多，装完越不需要联网（APK 在 Releases 页）。

层镜像（base / runtime / dsh）走频道分发：App「内置官方频道」，或终端里 linuxctl update。本页由 CI 生成（每次发布重写），别手工改 gh-pages。
